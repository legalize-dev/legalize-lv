# Speciālo ierīču izmantošanas kārtība A, B un C kategorijas kritiskās infrastruktūras objekta apsardzē

Ministru kabineta noteikumi Nr. 147 Rīgā 2026. gada 17. martā (prot. Nr. 15 43. §)

Izdoti saskaņā ar Apsardzes darbības likuma 21. panta piekto daļu

##### 1. Noteikumi nosaka to speciālo ierīču veidus, kuras atļauts izmantot A, B un C kategorijas kritiskās infrastruktūras objektu apsardzē, šo ierīču iegādes, glabāšanas un pielietošanas kārtību.

##### 2. Noteikumi neattiecas uz speciālajiem radiolīdzekļiem, kurus nevēlamu radiosakaru pārtraukšanai vai ietekmēšanai A, B un C kategorijas kritiskās infrastruktūras objektu apsardzē pielieto atbilstoši normatīvajiem aktiem, kas regulē elektronisko sakaru jomu un noteic speciālo radiolīdzekļu izmantošanas kārtību.

##### 3. A, B un C kategorijas kritiskās infrastruktūras objekta apsardzē tā apsardzes darbiniekiem atļauts izmantot šādu veidu speciālās ierīces:

3.1. ierīces kinētiskai iedarbībai uz attālināti vadāmām ierīcēm;

3.2. ierīces elektroniskai pretdarbībai attālināti vadāmām ierīcēm.

##### 4. Speciālās ierīces, kuras atļauts izmantot A, B un C kategorijas kritiskās infrastruktūras objekta apsardzē, iegādājas attiecīgā kritiskās infrastruktūras objekta īpašnieks vai tiesiskais valdītājs.

##### 5. Speciālās ierīces, kuras atļauts izmantot A, B un C kategorijas kritiskās infrastruktūras objekta apsardzē, attiecīgā kritiskās infrastruktūras objekta īpašnieks vai tiesiskais valdītājs glabā kritiskās infrastruktūras objektā, nodrošinot, ka piekļuve tām ir tikai apsardzes darbiniekiem, kuri pilda attiecīgā objekta apsardzes pienākumus.

##### 6. Pirms šo noteikumu 3. punktā minēto speciālo ierīču izmantošanas A, B un C kategorijas kritiskās infrastruktūras objekta apsardzē attiecīgā kritiskās infrastruktūras objekta īpašnieks vai tiesiskais valdītājs saņem nepieciešamās atļaujas atbilstoši normatīvajiem aktiem, kas regulē Latvijas Republikas gaisa telpas izmantošanas kārtību attiecībā uz atsevišķām darbībām.

##### 7. Lai pārtrauktu attālināti vadāmas ierīces neatļautu pārvietošanos apsargājamā objekta teritorijā, tā aizsargjoslā vai gaisa telpā virs tām, nodarot minētajai ierīcei bojājumus vai iznīcinot, notverot vai nosēdinot to, A, B un C kategorijas kritiskās infrastruktūras objekta apsardzes darbinieks pielieto šo noteikumu 3. punktā minētās speciālās ierīces, ievērojot to ražotāja noteiktās lietošanas prasības.

##### 8. Apsardzes darbiniekam speciālās ierīces aizliegts pielietot, radot apdraudējumu civilās aviācijas drošībai vai citu gaisa telpā esošu lidaparātu drošai kustībai.
